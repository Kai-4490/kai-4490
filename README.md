## `./projects`

### [ThreatDetection](https://github.com/Kai-4490/ThreatDetection)

**AI-Powered Network Intrusion Detection System**

A portfolio-focused NIDS combining three independently trained models across general, IoT, and enterprise network environments.

The system is being designed around:

* NetFlow-based network traffic analysis
* Multiple IDS models trained on different environments
* Cross-dataset generalization testing
* Per-class weighted ensemble predictions
* Behavioral analysis of network activity
* Historical source/destination context
* Risk scoring and threat classification
* Explainable detection results
* Replayed flow data for simulated real-time detection

The final system is intended to distinguish between known threats and unknown/anomalous traffic rather than forcing every flow into a known attack category.

**Stack:** Machine Learning · Network Security · NetFlow · Python · Data Analysis
